# Board repo template

Files to copy into a Glasnost board repository.

| File | Purpose |
|---|---|
| `AGENTS.md` | Agent guidance; points to the central review process |
| `resources/REFERENCES.md` | Reference manifest skeleton |
| `gitignore.append` | Lines to append to the board's `.gitignore` |
| `.github/ISSUE_TEMPLATE/finding.md` | Issue form for review findings |
