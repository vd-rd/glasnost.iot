# Glasnost

Central repository for the Glasnost open-hardware SBC family and its capes: the catalogue, shared standards, the design-review process, templates for board repos, and shared tooling. Published as a documentation site (`docs/`, MkDocs Material).

| Path | Contents |
|---|---|
| `docs/catalogue/` | All Glasnost boards: SoC, status, links |
| `docs/standards/` | Cross-board standards (header pinout, naming, form factor) |
| `docs/review/` | Design-review process, checklist, house rules, references format, tooling |
| `docs/journal/` | Cross-board journal (blog) |
| `templates/board-repo/` | Files to copy into a board repo |
| `scripts/` | Shared review/helper scripts |

Board-specific design files, references and findings live in each board's own repository.
